## 4. What this report does not cover

- **Hints and lesson text** (`hints`, `lesson-plans-k5.json`) were not checked.
- **Spoken audio content.** Whether an MP3 actually says its text needs a transcript; that is not deterministic and was not attempted. Only file existence and, where a generation record exists, text equality were checked.
- **Visual rendering of the iOS views** was inferred from the Swift source (which payload fields are read), not from running the app. The spatial SwiftUI code was written without a Swift toolchain in the authoring environment and has **not been compiled or run**; build and run `MathQuestKidsTests` in Xcode before shipping.
- Reference tables (shape facts, rotational symmetry, solid clues, piece-set geometry, net folding) are small closed sets printed at the top of the script; they are the only external knowledge used and are open to review.
- `symmetryMirror` correctness cannot be verified independently: its options contain only a boolean flag.
